# 目录文档路径右键复制修复记录

日期：2026-07-27

基线：`main` / `a9f3194`

## 问题

- 现象：在思维导图目录中右键节点后，“复制文档路径”菜单被其他功能顶掉或立即消失。
- 触发条件：右键菜单打开前复用了左键节点选择回调；当前左键选择会收起目录抽屉，并在导图模式下切换到并排文档。
- 影响：目录组件随抽屉收起而隐藏，用户无法稳定点击复制文档路径；同一菜单内的终极目录和删除操作也受到影响。
- 数据风险：问题属于 UI 事件职责冲突，不涉及导图、节点文档或数据库内容变更。

## 处理

- 左键单击和 Enter/Space 继续负责选择节点、收起目录并打开文档。
- 右键只阻止浏览器默认菜单并打开目标节点的操作菜单，不再触发节点选择或工作区切换。
- “复制文档路径”恢复为右键菜单首项。
- “设为终极目录/恢复下级目录”和“删除”继续保留在同一菜单中。
- 在目录边界专项 QA 中增加事件隔离和菜单顺序契约，防止后续功能再次覆盖复制入口。
