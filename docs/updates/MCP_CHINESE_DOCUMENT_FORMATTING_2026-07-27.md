# MCP 中国文章排版优化（2026-07-27）

## 基线

- 分支：`main`
- 起点提交：`4f53a691af496059a01451a5f4747614c6074ba5`
- 影响模块：独立 stdio MCP、桌面/HTTP MCP、节点文档文本模板、已有文档样式整理、MCP 技能与使用文档。
- 不涉及：数据库表结构、历史快照批量改写、导图/文档分屏界面、DOCX 导出规则。

## 变更

- 新写入和追加文本采用中国文章层级：可选文章标题、`一、`、`（一）`、`1.`、`（1）`。
- 正文使用宋体、两端对齐、比例行距和两个全角空格的首行缩进；标题使用黑体层级，副标题与引用使用楷体。
- 输入空行只作为段落边界，不再生成大面积可见空白行。
- 中文正文安全规范中英文相邻间距与中文标点，同时保护 URL、Windows 路径、邮箱、代码、公式、列表符号和树形缩进。
- `format_node_document` 复用同一套字体、层级、对齐和行距，但逐字保留所有编辑器 `value`，不补写缩进字符。
- 修复 Windows 路径占位符被数学下标处理破坏、URL 被误判为字段标签、项目列表被误判为 ASCII 树的问题。

## 风险与兼容

- 只影响此后通过 MCP 的文本写入、追加和显式样式整理；不会自动批量修改历史文档。
- 直接传入完整 snapshot 的高级写入仍以快照内容为准，不强制重排复杂表格、分栏和嵌入块。
- 覆盖、追加和样式整理继续使用 `expectedSnapshotId` 乐观锁；没有数据库迁移。
