# 思维导图视口滚动条修复记录

日期：2026-07-27

基线：`main` / `2fcc8b7`

第二轮修正版基线：`main` / `2415994`

## 问题与影响

- 现象：思维导图底部水平滚动条偶发无法拖动；同一套交互实现也影响右侧垂直滚动条。
- 触发条件：命中范围仅 10px，且拖动依赖组件维护 Pointer Capture；窗口抢焦点、指针取消、布局切换或组件重挂载时，拖动生命周期可能中断。
- 影响范围：导图单页、导图与节点文档并排、缩放后的大画布视口移动。
- 数据风险：问题只影响视口交互，不涉及导图节点、文档正文或数据库结构。

## 处理

- 第一版使用透明原生 `input[type="range"]` 承接拖动，但其原生小滑块与界面显示的长滑块命中模型不一致，只能保证从控件中心起拖，不能覆盖用户从可见滑块边缘或快速起拖的路径。
- 修正版统一显示与交互模型：可见滑块的整个面积都能抓取，轨道点击仍以滑块中心对齐。
- 拖动期间使用本地位置保持即时反馈，导图适配器更新按动画帧合并，避免 React 状态回流抢回鼠标位置。
- 仅在按住鼠标期间注册文档级移动和结束监听；通过 `AbortController` 在松开、取消、失焦、页面隐藏、布局切换或组件卸载时统一清理。
- 将水平高度和垂直宽度的有效命中范围进一步扩大到 26px，视觉轨道仍保持紧凑。
- 保留键盘方向键、PageUp/PageDown、Home/End 操作和可访问滚动条语义。
- 不改变导图适配器的视口换算与移动接口。
