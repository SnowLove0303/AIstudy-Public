# 知识库导图文档并排工作区变更记录

日期：2026-07-27

基线：`main` / `e70ff19`

## 变更范围

- 新增知识库并排布局模块，支持导图、并排、文档三种知识工作区呈现。
- 顶部工作区入口加入“并排”。
- 知识库目录和导图目录由固定列改为默认收起的覆盖式抽屉。
- 导图/文档分隔线支持指针拖动、方向键调整、双击或 Home 复位。
- 分栏比例按课程保存在本机 UI 偏好中。
- 小窗口不能同时满足最小宽度时，并排模式降级为文档单面板。
- 渲染进程与主进程的课程工作区模式契约加入 `split`。
- 新增 `validate-knowledge-split-workspace.mjs` 专项结构校验。

## 数据与兼容性

- 未执行数据库断开、删除、清空、迁移、字段调整或数据结构改动。
- 未修改导图和节点文档的真实保存链、快照协议及版本记录。
- 历史课程的 `mindmap`、`word`、`textbook` 模式继续兼容；未知值继续回退为 `mindmap`。
- 新 UI 偏好键：`aistudy:knowledge-split-ratio:<courseId>`。删除该键只会恢复 60/40 默认比例，不影响业务数据。

## 风险与处置

| 风险 | 触发条件 | 影响 | 处置 |
| --- | --- | --- | --- |
| 拖动事件过密 | 长时间快速左右拖动 | 渲染抖动、CPU 峰值 | 使用 `requestAnimationFrame` 合并更新，只在结束时持久化 |
| 面板过窄 | 窗口宽度小于 789px | 两侧内容不可读 | 自动降级为文档单面板，并保留顶部模式切换 |
| 拖动中断 | 指针取消、窗口失焦或组件卸载 | 光标/选择状态残留 | 统一清除捕获状态与全局样式，保留最后有效比例 |
| 目录抢占面积 | 左右目录同时常驻 | 主编辑区不足 | 默认收起、覆盖显示、互斥打开、选择后关闭 |
| 隐藏导图重绘 | 文档单面板或窄屏模式下导图不可见 | SVG 滚动条反复计算导致屏闪 | 不可见时卸载导图实例；尺寸通知按帧合并并去重 |
| 节点回调不稳定 | 主页面用每次渲染新建的函数包装节点 setter | 导图加载 effect 被反复触发，窗口持续屏闪 | 直接传入稳定的 React setter，并加入专项静态校验 |
| 模式状态不兼容 | 旧版本读取到 `split` | 旧版本不识别 | 旧版归一化逻辑会回退导图；不影响课程内容 |

## 真实验证

- 全量构建与所有既有 QA 通过。
- 离屏真实 Electron 运行连接现有课程，连续稳定后执行真实指针拖拽。
- 默认：导图 768px / 文档 503px；左拖约 90px 后：687px / 584px；双击恢复默认。
- 目录抽屉默认收起，主工作区宽度保持 1280px。
- 验证未输入或修改文档正文，结束时恢复导图模式。

## 回滚路径

优先使用本次独立提交进行 `git revert <commit>`。若需文件级回滚：

1. 删除 `src/renderer/features/knowledge/` 和专项 QA。
2. 恢复 `MindMapWorkspace.tsx`、`main.tsx`、`styles.css`、`courseTypes.ts`、`electron/main.ts` 与 `package.json` 的本次变更。
3. 重新运行 `npm run build`。

无需回滚或迁移数据库。遗留分栏比例可保留；如用户希望复位，可在应用中双击分隔线。
