# 知识库导图文档并排工作区

## 一、目标

用户在同一个知识库工作区中查看思维导图，同时编辑当前节点绑定的真实文档。知识库目录和导图目录只在需要导航时出现，不能永久挤占导图与文档的编辑面积。

## 二、需求边界

1. 主工作区支持“导图”“并排”“文档”“教材”四种模式。
2. 并排模式左侧为真实思维导图，右侧为当前节点的真实文档，不创建副本、不使用示例内容。
3. 导图与文档之间使用一条纵向分隔线。用户可以左右拖动调整面积，双击分隔线恢复默认比例。
4. 默认比例为导图 60%、文档 40%；导图最小宽度 360px，文档最小宽度 420px。
5. 比例按知识库分别保存，仅保存 UI 偏好，不进入课程、导图或文档业务数据。
6. 窗口不足以同时满足两个最小宽度时，并排模式自动降级为文档单面板；用户仍可通过顶部“导图”切回。
7. 知识库目录和导图目录改为左右覆盖式抽屉。默认收起，展开时覆盖主工作区，选择完成后自动收起；两个抽屉互斥，点击遮罩关闭。
8. 选择导图节点时，当前文档按 `courseId + mindMapId + nodeId` 重新绑定。通过右侧目录选择节点时，系统进入并排模式并关闭目录抽屉。

## 三、实现方案

### 3.1 模块边界

- `KnowledgeSplitWorkspace.tsx` 只负责布局、拖拽、键盘调整、响应式降级和比例偏好。
- `MindMapWorkspace.tsx` 继续负责导图生命周期、模式切换前保存以及节点选择。
- `KnowledgeDocumentWorkspace.tsx` 继续负责真实文档读取、编辑、版本快照和保存。
- `main.tsx` 只负责全局模式入口和目录抽屉状态，不承载拖拽算法。

### 3.2 性能原则

- 不引入新的分栏依赖，避免增加运行时和包体。
- 拖动期间直接更新 CSS 变量，并通过 `requestAnimationFrame` 合并高频指针事件；仅在拖动结束后写一次偏好。
- 从导图进入并排模式不触发完整导图保存，因为编辑器继续挂载；仅进入文档单页或教材模式前沿用既有保存排空。
- 文档单独模式和窄屏降级时卸载不可见导图实例，避免 SVG 滚动条在隐藏画布上重复计算并降低内存占用。
- 并排宽度改变沿用导图画布已有 `ResizeObserver`，不创建轮询。
- 导图尺寸变化按动画帧合并，并忽略宽高未变化的重复通知。
- 目录使用覆盖式定位，开合不触发主编辑区列宽重排。

### 3.3 可用性

- 分隔线使用标准 `separator` 语义，可通过左右方向键微调，按 Home 或双击恢复默认比例。
- 拖拽时设置全局横向调整光标并禁止文字选择；指针取消、失去捕获或组件卸载时清理状态。
- 分隔线视觉保持克制，仅在悬停、键盘聚焦或拖动时强调。

## 四、数据与风险边界

- 本功能不改 MySQL 表、字段、迁移或数据结构。
- 文档仍通过现有真实 API 和快照版本链保存；不改变覆盖策略，也不增加新的本地正文来源。
- 新增的 `localStorage` 项只保存知识库对应的分栏比例，读取或写入失败不会阻断工作区。
- 原有导图、文档、教材模式保留；旧课程的未知模式值仍归一化为导图模式。

## 五、验证范围

1. 全量构建、类型检查和既有数据边界校验。
2. 专项结构校验：模式契约、真实工作区挂载、抽屉布局、最小宽度、窄屏降级、拖拽和键盘能力。
3. 真实 Electron 应用验证：抽屉覆盖、并排渲染、节点切换、拖拽、双击复位、四种模式切换和窗口缩放。
4. 不创建测试课程、不写示例数据、不修改现有文档正文。

## 七、真实验证结果

- 在隐藏的真实 Electron + preload + 现有课程环境中连续稳定运行，无重复装载与 CPU 异常增长。
- 1280px 主编辑区默认并排结果：导图 768px、分隔线 9px、文档 503px。
- 分隔线向左拖动约 90px 后：导图 687px、文档 584px。
- 双击分隔线后恢复 768px / 503px。
- 左右目录默认在主编辑区之外隐藏，展开状态不改变主编辑区 1280px 宽度。

## 六、回滚

回滚时移除知识并排模块与专项校验，恢复 `main.tsx` 的三模式入口和固定侧栏布局，并从渲染进程与主进程课程模式联合类型中删除 `split`。分栏比例属于无害 UI 偏好，旧版本会忽略，无需清理数据库或用户内容。
